# Contribution

First off, thanks for taking the time to contribute! ❤️

## Getting Started

### Installation

You need lastest version of npm.

```bash
npm install
npm run dev
```

### Issues

Feel free to create new features, fix bugs issues.

### Pull requests

Create pull requests to contribute.

### Tests

Tests run with [Vitest](https://vitest.dev/) and need Node 22.22.2+, 24.15+ or 26+ (required by jsdom).

```bash
npm test
```

### Coding style

We use eslint and prettier for linting and formatting.

```bash
npm run lint
npm run format
```
